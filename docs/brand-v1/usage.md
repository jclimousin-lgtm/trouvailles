# Règles d'usage — Trouvailles V1

## Logo
Utiliser `trouvailles-horizontal.svg` pour les en-têtes desktop.
Utiliser `trouvailles-stacked.svg` pour les espaces carrés ou compacts.
Utiliser `trouvailles-symbol.svg` pour favicon, avatar, app icon et petits emplacements.
Utiliser `trouvailles-monochrome.svg` lorsque la reproduction couleur n'est pas possible.

## Couleur
Le vert profond porte le signal positif et l'action principale.
L'orange est un accent : nouvelle opportunité, baisse, signal secondaire.
L'ivoire constitue le fond éditorial privilégié.
L'encre sert au texte et aux éléments structurants.

## Confiance
Ne pas employer le vert pour transformer une donnée incertaine en certitude.
Les trois états V1 sont :
- Confiance élevée
- Confiance moyenne
- Données insuffisantes

## Décote
La décote doit rester visuellement liée à la comparaison :
prix demandé / valeur de marché estimée.
