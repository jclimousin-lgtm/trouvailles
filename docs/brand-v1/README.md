# Trouvailles — Brand Assets V1

Pack d'assets dérivé de la planche de charte graphique V1 validée le 4 septembre 2026.

## Identité
- Direction : éditoriale, sobre, chaleureuse, légèrement « chasse au trésor ».
- Concept : étiquette de prix + loupe / détection.
- Signature : « Ce qui vaut vraiment le coup. »

## Palette
- Vert profond : #176B52
- Vert clair : #B8DCC7
- Orange signal : #E8873D
- Encre : #20201E
- Ivoire : #F7F4EC

## Typographies
- Titres / accents : Georgia / Times New Roman en fallback système.
- Interface : Inter / system-ui.

## Responsive
Le fichier `css/trouvailles.css` contient les bases responsive :
- PC : > 1024 px
- Tablette : 721–1024 px
- Mobile : <= 720 px

## Structure
- `assets/logo/` : logos principal, empilé, monochrome, symbole.
- `assets/icons/` : icônes fonctionnelles.
- `assets/illustrations/` : illustration éditoriale vectorielle.
- `assets/patterns/` : motifs graphiques.
- `assets/ui/` : éléments visuels réutilisables.
- `css/` : variables, composants et responsive.
- `docs/` : règles d'usage.

Les SVG sont volontairement indépendants, sans dépendance externe.
